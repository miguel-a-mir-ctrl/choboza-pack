# choboza-pack

มอดเล็กสองตัวสำหรับ Claude Code ทำมาให้มือใหม่ใช้ ทำงานเป็นโค้ดในเครื่องของคุณ

## มีอะไรบ้าง

| มอด | ทำอะไร |
|---|---|
| **usage-line** | แถวเดียวเหนือช่องพิมพ์: การใช้งาน 5 ชั่วโมงและรายสัปดาห์, โมเดลปัจจุบัน, effort และบริบท ยังแสดงภาระงาน CPU, RAM และ GPU และแสดง NPU ถ้าระบบรองรับ |
| **lab-panel** | แผงด้านข้างที่มีรายการไฟล์สีสัน ไฟล์ที่ Claude อ่านหรือแก้จะกระพริบสักครู่ แท็บเล่นซ้ำแสดงการแก้ไขของรอบล่าสุด แท็บโน้ตให้คุณเก็บบันทึกของตัวเองได้ แท็บสเก็ตช์ให้คุณวาดเครื่องหมายแล้วส่งให้ Claude ได้ (บน Windows วาดทับรูปจากคลิปบอร์ดได้ด้วย) |

## ติดตั้ง

พิมพ์คำสั่งเหล่านี้ใน Claude Code:

```
/plugin marketplace add miguel-a-mir-ctrl/choboza-pack
/plugin install usage-line@choboza-pack
/plugin install lab-panel@choboza-pack
```

จากนั้นเปิด Claude Code ใหม่ (หรือรัน `/reload-plugins`) เปิดแผงด้วย `/panel` หรือคลิก `[แผง]` เหนือช่องพิมพ์ (เปิดได้แม้ Claude กำลังทำงาน)

## ตั้งค่า

เปลี่ยนได้ในการตั้งค่าปลั๊กอิน (`/plugin`)

| มอด | ตั้งค่า | ค่า |
|---|---|---|
| ทั้งสองตัว | `language` | `auto` (ภาษาของระบบ), `ko`, `en`, `zh-Hans`, `zh-Hant`, `ja`, `es`, `fr`, `id`, `th` |
| usage-line | `gpu` | `auto` (GPU ที่ทำงานหนักที่สุด, ค่าเริ่มต้น), `nvidia`, `amd`, `intel`, `off` |
| lab-panel | `icons` | `nerd` (ไอคอนประเภทไฟล์, ค่าเริ่มต้น), `plain` (ตัวอักษรธรรมดา) |
| lab-panel | `autoOpen` | `true` = เปิดแผงเมื่อเริ่มเซสชัน (ค่าเริ่มต้นคือ `false`) |
| lab-panel | `tabsDir` | โฟลเดอร์ของแท็บโน้ต ถ้าเว้นว่าง = `~/.claude/choboza-pack/panel` |

## ไอคอนแสดงเป็นกล่องสี่เหลี่ยมใช่ไหม?

รายการไฟล์ใช้ไอคอนจาก [Nerd Font](https://www.nerdfonts.com/font-downloads) ถ้าเห็น □ แทนไอคอน ให้ทำอย่างใดอย่างหนึ่ง:

- ติดตั้ง Nerd Font แล้วเลือกในการตั้งค่าฟอนต์ของเทอร์มินัล
- เปลี่ยน `icons` เป็น `plain`

## หมายเหตุ

- แทบไม่ใช้โทเคน: ม็อดทำงานบนพีซีของคุณ และไม่เพิ่มอะไรให้ Claude อ่านเลย ยกเว้นข้อความสั้น ๆ (ประมาณ 20 โทเคน) เมื่อบริบทเกิน 100k เพื่อแนะนำ `/compact` หรือเริ่มเซสชันใหม่ วัดเมื่อ 2026-11-01: โทเคนขาเข้าเท่ากันทั้งเปิดและไม่เปิดแพ็ก (อยู่ในค่าคลาดเคลื่อนปกติ)
- ทดสอบบน Windows เป็นหลัก Linux และ macOS ก็ใช้ได้แต่ทดสอบน้อยกว่า (บน macOS ไม่แสดง NPU)
- คำแปลที่ไม่ใช่ภาษาเกาหลีและภาษาอังกฤษเป็นการแปลด้วยเครื่อง ยินดีรับการแก้ไข
